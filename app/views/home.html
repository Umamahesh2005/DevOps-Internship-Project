Welcome to the DevOps Internship Project

This application demonstrates an automated DevOps deployment pipeline using modern cloud and container technologies.

🚀 CI/CD Pipeline

Every code change pushed to the GitHub repository automatically triggers the CI/CD pipeline.

  • GitHub for source code management
  • GitHub Actions for CI/CD automation
  • Docker for application containerization
  • Docker Hub for container image storage
  • Google Cloud Platform for deployment
  • Terraform for infrastructure management

⚙️ Automated Deployment

The application is automatically built, tested, packaged into a Docker image, pushed to Docker Hub, and deployed to the Google Cloud server.

✅ Application Status

The application is currently running successfully inside a Docker container on the Google Cloud VM.
