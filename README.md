# Automated Web Application Deployment with CI/CD

## Project Overview

This project demonstrates a complete DevOps workflow by building a web application, containerizing it with Docker, provisioning cloud infrastructure using Terraform, and automating deployment using GitHub Actions.

## Technologies Used

- HTML
- CSS
- JavaScript
- Node.js
- Express.js
- Docker
- Docker Compose
- Terraform
- AWS EC2
- Git
- GitHub
